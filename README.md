Projekt został stworzony na potrzeby obrony pracy licencjackiej.

Program służy do usprawienia podstawowej pracy na warsztacie mechanicznym. Pozwala na rejestrację klientów i ich samochów wraz z podstawowymi danymi. 

Dodatkowym atutem programu jest fakt tworzenia go współpracując z działającym warsztatem co pozwoliło na szybki feedback i implementację odpowiednich funkcji takich jak statystki.
